# מתרגלים ומצליחים – מערכת תרגול חשבון

מערכת PWA בעברית, RTL, עבור עילאי ורואי.

## מה כלול
- שני תלמידים: עילאי ורואי.
- נושאים בהתאם לשקף:
  - חיבור וחיסור עד 20.
  - חיבור וחיסור עד 100.
  - כפל וחילוק עד 100.
  - מספרים ופעולות עד 1,000.
  - חיבור וחיסור במאונך.
  - בעיות מילוליות.
  - גיאומטריה ומדידות: אורך, מצולעים, זמן וגופים.
  - תרגול מעורב.
- 10 שאלות בכל סבב.
- תשובה נכונה בניסיון ראשון: +10 נקודות.
- תשובה נכונה בניסיון שני: +5 נקודות.
- אחרי טעות ראשונה: ניסיון נוסף עם חיזוק.
- אחרי טעות שנייה: משפט העצמה וממשיכים.
- אנימציית הצלחה/קונפטי.
- שמירת ניקוד והתקדמות במכשיר באמצעות localStorage.
- דוח לכל תלמיד + סיכום ניקוד של שניהם.
- שיתוף דוח, הדפסה וייצוא ל-PDF דרך הדפדפן.
- התקנה כ-PWA באנדרואיד ובמחשב; ב-iPhone אפשר להוסיף למסך הבית דרך Safari.

## הפעלה מקומית
Service Worker דורש HTTP/HTTPS. אפשר להשתמש ב-Python:

```bash
python3 -m http.server 8080
```

ואז לפתוח:
http://localhost:8080

לבדיקה מטלפון באותה רשת, להפעיל את השרת עם ה-IP של המחשב ולפתוח את כתובת ה-IP בטלפון.

## פריסה מומלצת
להעלות את התיקייה ל-GitHub Pages, Netlify, Vercel או שרת HTTPS. לאחר הפריסה הדפדפן יציע התקנה כאפליקציה.

## הערה
זו גרסת MVP מקומית: הנתונים נשמרים במכשיר/דפדפן. לגרסת מורה מלאה כדאי להוסיף חשבון מורה, סנכרון לענן, מאגר תרגילים גדול, ניהול רמות, דוחות לפי תאריכים ומסד נתונים.
